knowledgelake — pipeline

Messy documents on any subject in (PDFs, scans, screenshots, text) → a clean, de-duplicated, searchable knowledge base out
📄 text PDFs🖨 scanned PDFs🖼 infographic images / GIFs📝 .txt / .md🗜 .zip / folders
1 · EXTRACT

Text + OCR

pdftotext for text layers; Tesseract OCR fallback when a PDF has <50 chars/page or the input is an image

→
2 · PARSE

Q&A segmentation

Numbered items, Q:/A: markers, bare “…?” lines. Code lines auto-fenced for rendering

→
3 · CLASSIFY

Topic + section

Topics discovered automatically (or a preset), then rules + a classifier trained on the KB itself. Low confidence → review queue

→
4 · DEDUPE

Merge duplicates

Lexical Jaccard with meaning-critical tokens, plus a record-linkage model on embeddings. Unsure pairs → review queue

→
5 · ANSWER

LLM fill-in

Question-only items answered via Anthropic API, retries/back-off, flagged ✎ as AI-written

→
6 · STORE

Topic JSON KB

Idempotent append: new batches checked against stored questions; sources merged

→
7 · RENDER

PDF per topic

ReportLab: cover stats, clickable contents, sections, code boxes, source on every answer
